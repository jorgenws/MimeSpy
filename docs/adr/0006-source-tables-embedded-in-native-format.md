# Source tables embedded in their native format, not pre-converted JSON

[ADR 0003](0003-signature-and-mimetype-data-as-embedded-json.md) embedded both source tables as JSON so a data refresh was "drop in a new file" with no conversion step - convenient because mime-db and Gary Kessler's file-signature table were both already published as JSON. Neither of their replacements is JSON: [ADR 0005](0005-mimetype-table-sourced-from-apache-mimetypes.md) moved the mime-type table to Apache's plain-text `mime.types` format, and the file-signature table (`Resources/file_signatures.csv`) is now sourced as CSV instead of JSON. Converting either back into a JSON intermediate on refresh would be an extra step with no payoff, so `MimeTypeIndex` and `SignatureIndex` now parse each file's native format directly instead. The CSV has no quoted or comma-escaped fields anywhere in the data, so it's read with a plain per-line `Split(',')` rather than adding a CSV parsing library - keeping the library free of external runtime dependencies, per AGENTS.md's "one layer, don't make it complicated."
